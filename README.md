# ✈️ TravelGo — Flight Booking Website

TravelGo is a responsive flight booking website designed to provide a smooth, user-friendly travel booking experience. It features a multi-step flight booking flow covering flight selection, passenger information, payment, booking confirmation, and digital ticket details.

## 🌐 Live Demo

**[View TravelGo Live](https://anjaliyadav07.github.io/TravelGo/)**

## ✨ Features

* 🏠 Travel-focused landing page
* 🔐 Login and signup interfaces
* ✈️ Flight browsing and selection
* 👤 Passenger information
* 💳 Payment interface
* 🎫 Digital flight ticket
* 📋 Booking details
* ✅ Booking confirmation
* 📱 Responsive design
* 🔄 Complete multi-page booking workflow

## 🛠️ Tech Stack

* **HTML5** — Website structure and semantic markup
* **CSS3** — Styling, layouts, animations, and responsive design
* **JavaScript** — Client-side interactions and booking workflow
* **GitHub Pages** — Deployment

## 🔄 Booking Flow

```text
Home
  ↓
Flight Selection
  ↓
Passenger Details
  ↓
Payment
  ↓
Booking Confirmation
  ↓
Digital Ticket
```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/anjaliyadav07/TravelGo.git
```

### Open the project

```bash
cd TravelGo
```

Open `index.html` in your browser, or use the Live Server extension in VS Code.
